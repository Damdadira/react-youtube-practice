# YoungTube
유튜브 인터페이스를 리액트로 제작한 프로젝트입니다.<br/>
**YouTube Data API**를 활용해 실제 데이터를 연동하고 **동영상 시청, 검색, 관련 동영상 탐색, 댓글과 답글, 다크 모드** 등 다양한 기능을 구현했습니다.
